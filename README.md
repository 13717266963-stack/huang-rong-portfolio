# 黄蓉 · 创意设计作品集

供 GitHub Pages 发布的静态网站，包含全部图片和 16 条作品视频。

## 发布

使用公开仓库，在 Settings → Pages 选择 Deploy from a branch，发布 main 分支的 / (root)。保留 `.nojekyll`。

无需安装依赖或在线构建。可用于账号主页，也可用于项目地址，资源路径已适配子目录。无需购买域名。

迁移自已发布的作品集版本 2，源码提交 `7a8ccf63581150bca824d5b1747e0e36344041ed`。

发布后仍需实测大陆手机网络访问、图片切换及全部视频的播放和拖动进度。
